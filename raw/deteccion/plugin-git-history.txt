    fix(quota): use official CLI user-agent on quota summary and available models endpoints (#61)

    the 'Gemini Models' quota group when requested with the official CLI User-Agent.
    With the generic IDE header, Google strips the Gemini group and only returns
    the 'Claude and GPT models' group.
    
    - Bump fallback CLI version to 1.4.7 (matching upstream release).
    - Provide getAntigravityCliUserAgent() helper in constants.ts.
    - Pass getAntigravityCliUserAgent() to fetchQuotaSummary and fetchAvailableModels.
    - Rebuild dist artifacts.
