# --- where to look ---
# Section 1 gives the 4,066 total and the per-window spread; the same number
# appears in the payload census line raw/payload.txt:62 (psin=4066).
# Section 2 is the shape histogram: 3,958 seven-chunk chains, 78 bare PSIN
# headers, and one PSIN -> PMAP -> ... -> CHKS variant that no document in this
# repository describes yet.
# Section 3 states the successor count (23,829) because that is how the walk
# advances, so the 100% row is by construction; it is not independent evidence.
# What discriminates is the number of streams that end exactly at the inflated
# size (3,959) and the body equations of sections 4-5, which a boundary shifted
# by 8 bytes would not satisfy. The 7,943 plausible four-byte tags eight bytes
# late show why a loose tag check is not enough either. No chunk declares a
# length below 8.
# Sections 4 and 5 are the body layouts that docs/PSIN.md:55-60 quotes: the
# two-phase reading lands exactly on the body end 3,983 times for LSCH and 3,980
# times for LENM, while the interleaved reading of PercyStar src/psin.rs:235
# reaches the end in only 2,929 of the 3,980 LENM bodies.
# Section 7 lists the 107 streams whose last chunk declares a length past the
# inflated body, all of them exactly 65,536 bytes long. They are container
# prefixes cut by the window, so their bodies stay out of the layout counts.
